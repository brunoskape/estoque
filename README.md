# Sistema de Estoque

Sistema desktop de controle de estoque desenvolvido com **Python + CustomTkinter + SQLite**.

## Requisitos

- Python 3.10+

## Instalação

```bash
pip install -r requirements.txt
```

## Execução

```bash
python main.py
```

## Gerar executável (PyInstaller)

```bash
pyinstaller --onefile --windowed main.py
```
